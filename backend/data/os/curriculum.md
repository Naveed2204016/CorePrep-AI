# Operating Systems Interview Corpus

## OS Architecture & System Calls
Cover kernel and user mode, interrupts, traps, system calls, monolithic and microkernel structures.
## Processes
Understand process states, PCBs, creation, termination, zombies, context switches, and isolation.
## Threads & Multithreading
Compare processes and threads, user and kernel threads, concurrency, parallelism, and threading models.
## CPU Scheduling
Analyze FCFS, SJF, priority, round-robin, multilevel queues, waiting time, turnaround, and response time.
## Interprocess Communication
Use pipes, queues, shared memory, signals, sockets, and RPC with their synchronization trade-offs.
## Synchronization
Reason about races, critical sections, mutexes, semaphores, monitors, condition variables, and atomic operations.
## Deadlocks
Apply the four conditions, resource graphs, prevention, avoidance, detection, recovery, and Banker's algorithm.
## Memory Management
Cover address binding, allocation, fragmentation, paging, segmentation, and translation hardware.
## Virtual Memory
Understand demand paging, page faults, replacement policies, locality, working sets, and thrashing.
## File Systems
Cover files, directories, inodes, allocation, free space, permissions, journaling, and recovery.
## I/O & Storage
Understand controllers, interrupts, DMA, buffering, caching, disk scheduling, SSDs, and RAID.
## Protection & Security
Apply access control, privilege levels, isolation, authentication, and common operating-system defenses.
## Virtualization
Compare type-1 and type-2 hypervisors, virtual machines, hardware assistance, and resource scheduling.
## Containers & Namespaces
Explain containers using processes, namespaces, cgroups, layered filesystems, and isolation boundaries.
## OS Performance & Observability
Diagnose CPU, memory, I/O, contention, load, latency, and resource exhaustion using system metrics.
