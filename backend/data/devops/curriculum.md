# DevOps Interview Corpus

## Linux Fundamentals
Use filesystems, permissions, users, processes, services, packages, logs, and resource inspection confidently.
## Shell Scripting
Automate safely with variables, quoting, pipes, conditions, loops, functions, exit codes, and strict failure handling.
## Git & Collaboration
Use focused commits, branches, merging, reviews, tags, and recoverable team workflows.
## Networking & DNS
Understand IP, routes, ports, DNS, HTTP, TLS, proxies, load balancers, and layered troubleshooting.
## Docker & Containers
Build and run containers using images, layers, volumes, networks, Compose, limits, and isolation.
## Container Images & Registries
Create small reproducible images, use tags and digests, scan artifacts, sign images, and manage registries.
## Kubernetes
Operate pods, deployments, services, ingress, configuration, secrets, probes, autoscaling, and rolling updates.
## Infrastructure as Code
Provision declarative infrastructure using state, plans, modules, remote backends, review, and drift detection.
## Configuration Management
Maintain desired server state with inventories, idempotent tasks, templates, secrets, and environment separation.
## Continuous Integration
Automate build, test, lint, scan, cache, and artifact stages with fast reliable feedback.
## Continuous Delivery & Deployment
Design promotion, approvals, rollbacks, blue-green, canary, feature flags, and progressive releases.
## Cloud Fundamentals
Understand compute, networking, storage, identity, managed services, regions, availability zones, and cost.
## Monitoring, Logging & Tracing
Collect telemetry, correlate symptoms, build dashboards, alert on user impact, and retain useful evidence.
## DevSecOps
Use least privilege, secrets management, dependency and image scanning, policy, and supply-chain controls.
## SRE & Incident Response
Define SLIs, SLOs, error budgets, on-call, runbooks, incident command, postmortems, and reliability improvements.
