# Frontend Development Interview Corpus

## Semantic HTML & Accessibility
Use meaningful elements, correct forms, keyboard support, focus management, labels, landmarks, and accessible names.
## CSS Fundamentals & Layout
Master cascade, specificity, inheritance, box model, positioning, Flexbox, Grid, and responsive design.
## JavaScript Fundamentals
Cover values, coercion, scope, closures, functions, objects, arrays, prototypes, modules, and the event loop.
## TypeScript
Use inference, unions, narrowing, interfaces, generics, utility types, and strict compiler settings.
## DOM & Events
Manipulate documents safely and understand event propagation, delegation, forms, and browser APIs.
## Browser Rendering
Trace HTML parsing, CSSOM, style, layout, paint, compositing, and the critical rendering path.
## HTTP & Web APIs
Use fetch, headers, status codes, cookies, CORS, JSON, aborting, retries, and asynchronous flows.
## React Components & Hooks
Build reusable components and use state, effects, refs, context, memoization, and custom hooks correctly.
## State Management
Separate local, shared, server, form, and URL state and avoid unnecessary global state.
## Forms & Validation
Build accessible controlled forms with boundary validation, useful errors, and safe submission states.
## Routing & Application Architecture
Organize routes, layouts, data loading, error boundaries, features, and reusable modules.
## Frontend Testing
Test behavior through unit, component, integration, accessibility, visual, and end-to-end layers.
## Web Performance
Improve Core Web Vitals, network loading, rendering, images, code splitting, caching, and bundle size.
## Frontend Security
Prevent XSS, CSRF, unsafe DOM use, clickjacking, insecure storage, and dependency compromise.
## Build Tools & Deployment
Use package managers, bundlers, environment configuration, source maps, CI, and static hosting.
