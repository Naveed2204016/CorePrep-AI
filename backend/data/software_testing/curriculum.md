# Software Testing and QA Interview Corpus

## Testing Fundamentals
Understand quality, verification, validation, test levels, test types, defects, and the limits of testing.
## Test Strategy & Planning
Define scope, risk, environments, data, responsibilities, entry criteria, exit criteria, and reporting.
## Test Case Design
Apply equivalence partitions, boundaries, decision tables, pairwise combinations, and state transitions.
## Unit Testing
Test small behaviors with deterministic setup, clear assertions, and maintainable mocks, stubs, or fakes.
## Integration Testing
Verify component boundaries, databases, external services, contracts, and failure interactions.
## System & End-to-End Testing
Validate complete user workflows in realistic environments while minimizing slow brittle tests.
## Regression, Smoke & Sanity Testing
Select suites for broad change confidence, initial build health, and focused verification.
## Black-Box & White-Box Testing
Compare behavior-based and structure-based methods including statements, branches, paths, and conditions.
## API Testing
Test methods, status codes, schemas, authentication, validation, idempotency, errors, and contracts.
## UI Test Automation
Build stable browser tests with semantic locators, explicit assertions, controlled data, and useful traces.
## Performance Testing
Measure latency, throughput, saturation, scalability, load, stress, spike, and endurance behavior.
## Security Testing
Test identity, authorization, sessions, input handling, dependencies, configuration, and common vulnerabilities.
## Defect Management
Report reproducible defects, assign severity and priority, triage, retest, and close with evidence.
## Testing in CI/CD
Run layered checks, parallelize feedback, control test data, preserve artifacts, and block unsafe releases.
## Quality Metrics & Risk-Based Testing
Prioritize by impact and likelihood and interpret coverage, defect, reliability, and escape metrics carefully.
