# Git and GitHub Interview Corpus

## Git Foundations
Understand distributed version control, snapshots, repositories, working trees, staging, and history.
## Repository Lifecycle
Initialize, clone, configure, inspect, ignore, and maintain repositories.
## Staging & Commits
Use diffs and the index to create focused, meaningful, reviewable commits.
## Branching
Create, switch, compare, track, and delete lightweight branches safely.
## Merging
Understand fast-forward and three-way merges, merge bases, and integration history.
## Rebasing
Rewrite local history intentionally and never casually rebase commits others depend on.
## Remotes
Fetch, pull, push, track branches, manage origins, and understand remote references.
## GitHub Pull Requests
Collaborate with forks, reviews, discussions, checks, approvals, and protected branches.
## Conflict Resolution
Read conflict markers and resolve merges, rebases, and cherry-picks while preserving intent.
## Undo & Recovery
Choose restore, reset, revert, reflog, and recovery actions according to whether history is shared.
## Tags & Releases
Use lightweight and annotated tags, semantic versions, release notes, and artifacts.
## Stashing & Cherry-Picking
Temporarily shelve work and selectively transfer individual commits without losing context.
## Git Internals
Understand blobs, trees, commits, references, HEAD, reachability, object storage, and packfiles.
## Team Workflows
Compare feature branching, trunk-based development, GitHub Flow, release branches, and review policy.
## GitHub Actions & Security
Automate checks and protect code with scoped permissions, secrets, scanning, and dependency updates.
