# DBMS Interview Corpus

## Database Fundamentals
Cover schemas, instances, DBMS architecture, data independence, and relational database responsibilities.
## ER Modeling
Model entities, attributes, relationships, cardinality, participation, and weak entities from requirements.
## Relational Model & Algebra
Understand relations, tuples, selection, projection, joins, products, division, and set operations.
## SQL Fundamentals
Write DDL and DML queries using filtering, grouping, aggregation, ordering, null handling, and CTEs.
## Joins & Subqueries
Choose inner and outer joins, correlated subqueries, set operations, and window functions deliberately.
## Keys & Constraints
Use candidate, primary, foreign, unique, check, and nullability constraints to preserve integrity.
## Normalization
Use functional dependencies to reach 1NF, 2NF, 3NF, and BCNF while understanding denormalization trade-offs.
## Indexes
Understand B-trees, hash indexes, composite order, selectivity, covering indexes, and write amplification.
## Transactions & ACID
Apply atomicity, consistency, isolation, durability, commit, rollback, and transactional boundaries.
## Concurrency Control
Cover locking, timestamps, optimistic control, MVCC, schedules, anomalies, and serializability.
## Isolation & Deadlocks
Compare isolation levels and handle lost updates, dirty reads, phantoms, deadlock prevention, and recovery.
## Storage & File Organization
Understand pages, records, heap and sorted files, buffers, and the cost of disk access.
## Query Processing & Optimization
Read execution plans and reason about scans, join algorithms, cardinality estimates, and cost-based choices.
## Replication & Partitioning
Compare replication, failover, horizontal and vertical partitioning, sharding, and rebalancing.
## Database Security
Apply roles, least privilege, parameterized queries, encryption, secrets, auditing, and backup protection.
