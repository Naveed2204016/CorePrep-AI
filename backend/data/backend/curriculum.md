# Backend Development Interview Corpus

## Backend & Server Fundamentals
Understand processes, threads, event loops, ports, request lifecycles, concurrency, and runtime trade-offs.
## REST API Design
Model resources and use methods, status codes, pagination, filtering, versioning, and idempotency correctly.
## Validation & Error Handling
Validate all boundaries and return stable, safe, observable, and actionable error responses.
## Authentication & Authorization
Compare sessions and tokens; implement identity, roles, permissions, ownership, and least privilege.
## SQL & Database Design
Model relational data, enforce constraints, query efficiently, and choose correct transaction boundaries.
## ORMs & Migrations
Understand object mapping costs, loading strategies, transactions, and safe forward/backward schema evolution.
## Caching
Use local and distributed caches with TTL, invalidation, eviction, consistency, and stampede prevention.
## Background Jobs & Queues
Design workers with retries, backoff, idempotency, scheduling, dead letters, and operational visibility.
## File & Object Storage
Validate and stream uploads, manage metadata, use object storage, and issue controlled signed access.
## Backend Testing
Test logic, services, APIs, databases, contracts, concurrency, and failures using reliable fixtures.
## Backend Security
Prevent injection, broken access control, SSRF, unsafe deserialization, secret leakage, and dependency attacks.
## Logging & Observability
Produce structured logs, metrics, traces, correlation IDs, health checks, dashboards, and alerts.
## Scalability & Reliability
Use stateless services, load balancing, timeouts, retries, circuit breakers, and graceful shutdown.
## Containers & Deployment
Package applications, configure environments, run migrations, manage secrets, and release safely.
## Backend Architecture
Apply layering, modularity, dependency inversion, domain boundaries, events, and explicit trade-offs.
