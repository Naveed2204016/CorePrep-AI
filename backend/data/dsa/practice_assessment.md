# DSA Practice and Assessment Blueprint

## Practice progression
For each group: explain concepts without notes, implement the central structure or algorithm, solve easy pattern-isolation problems, solve medium combination problems, then revisit errors after a delay. Prefer a small set of deeply reviewed problems over a large count of copied solutions.

## Assessment dimensions
- Concept accuracy: invariants, operation costs, constraints, and trade-offs.
- Pattern recognition: why a technique fits the input and goal.
- Implementation: correctness, edge cases, and clean state management.
- Complexity: justified time and auxiliary space.
- Communication: assumptions, brute force, optimization, and testing.

## Topic-group boundaries
Assess each focused roadmap topic at its own card boundary. Keep questions aligned to that card instead of adding a separate mixed-practice or final-review topic.

## Revision signals
Repeated off-by-one errors indicate binary-search or window-invariant revision. Missing visited-state handling indicates graph traversal revision. Incorrect or oversized DP state indicates recurrence-design revision. Unjustified complexity claims require foundations review.
