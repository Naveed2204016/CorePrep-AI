# DSA Interview Curriculum Map

## Prerequisite order
1. Big-O time and space analysis, basic mathematics, iteration, and recursion.
2. Arrays; strings; hashing; two pointers; sliding windows; prefix sums.
3. Linked lists; stacks; queues and deques.
4. Sorting; binary search; recursion; backtracking.
5. Trees and binary search trees; heaps; tries.
6. Graph representation, traversal, union-find, topological order, shortest paths, and minimum spanning trees.
7. Greedy reasoning; dynamic programming.

## Roadmap design rules
- Use one focused subject per roadmap card and never exceed 20 cards.
- Give every card a blog and a video that specifically teach that card's subject.
- Short plans teach representative patterns; longer plans add implementation, variants, spaced revision, and timed sets.
- Keep day ranges short enough to fit all focused subjects within the selected timeline.

## Interview outcomes
Learners should identify patterns, justify complexity, choose appropriate data structures, communicate trade-offs, implement clean solutions, test edge cases, and improve a brute-force solution.
