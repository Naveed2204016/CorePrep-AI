# Hashing, Strings and Linear Array Patterns

## Hash tables and sets
Understand expected O(1) insert, lookup, and delete; collisions; keys; frequency maps; and when ordering is not guaranteed. Practise two sum, duplicate detection, grouping anagrams, frequency counting, and longest consecutive sequence.

## Strings
Cover character counting, immutability costs, palindrome checks, parsing, substring vs subsequence, and basic pattern matching. Know when a rolling hash or trie is more suitable than direct comparison.

## Two pointers
Use converging pointers on sorted arrays, same-direction slow/fast pointers for compaction, and runner techniques for cycles. Problems include pair sum, valid palindrome, container area, deduplication, and partitioning.

## Sliding window
Maintain an invariant over a contiguous range. Fixed windows handle size-k aggregates. Variable windows expand and shrink based on a constraint. Problems include longest unique substring, minimum window, and maximum window sum.

## Prefix sums and intervals
Use prefix sums for repeated range queries and subarray-sum transformations. Cover difference arrays at an introductory level. Sort and merge intervals; handle endpoints consistently.
