# Complexity, Mathematics, Recursion and Backtracking

## Complexity
Analyze best, average, and worst-case time and auxiliary space. Recognize O(1), O(log n), O(n), O(n log n), O(n^2), O(2^n), and O(n!). Cover amortized dynamic-array growth and the difference between input space and auxiliary space. For recursive algorithms, count calls and maximum call-stack depth.

## Supporting mathematics
Review logarithms, powers, modular arithmetic, greatest common divisor, prime tests, and the sieve of Eratosthenes. Use these only where they support common coding problems.

## Recursion
Define base cases, state transitions, and invariants. Trace the call stack. Practise subsets, permutations, combinations, and recursive tree traversal.

## Backtracking
Use choose-explore-unchoose. Prune invalid branches. Core patterns include subsets, permutations, combination sum, word search, N-Queens, and Sudoku-style constraint search.

## Common mistakes
Missing base cases, exponential branching without pruning, copying state unnecessarily, incorrect shared mutable state, and claiming O(n) space while ignoring recursion depth.
