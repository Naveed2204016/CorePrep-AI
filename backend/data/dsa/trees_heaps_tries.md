# Trees, Binary Search Trees, Tries and Heaps

## Binary trees
Use recursive and iterative preorder, inorder, postorder, and level-order traversal. Understand height, depth, diameter, balance, complete vs full trees, and O(h) recursion space. Practise path sum, lowest common ancestor, serialization, subtree checks, and tree construction.

## Binary search trees
Maintain left-key < node-key < right-key under the chosen duplicate policy. Search, insert, and delete cost O(h): O(log n) when balanced and O(n) when skewed. Inorder traversal produces sorted order. Practise validation, kth smallest, predecessor/successor, and range queries.

## Tries
Store strings by prefix. Insert, exact search, and prefix search cost O(L) for key length L, trading memory for fast prefix operations. Practise autocomplete, word dictionary, and board word search.

## Heaps and priority queues
A binary heap provides O(1) peek and O(log n) insert/extract; heap construction is O(n). Practise top-k, kth largest, merging sorted streams, median from data stream, and scheduling. Know when a heap is preferable to sorting the whole input.
